# 🤖 E-Commerce AI Sales & Customer Support Telegram Agent

একটি সম্পূর্ণ স্বয়ংক্রিয়, বুদ্ধিমান এবং ২৪/৭ কার্যকর টেলিগ্রাম বট যা আপনার ই-কমার্স বিজনেসের জন্য **সেলস রিপ্রেজেন্টেটিভ** এবং **কাস্টমার সাপোর্ট এজেন্ট** হিসেবে কাজ করবে।

বটটি **Google Gemini API** (Gemini 2.5 Flash), **Python Telegram Bot** এবং **SQLite** প্রযুক্তির ওপর ভিত্তি করে নির্মিত।

---

## 🌟 প্রধান সুবিধাসমূহ (Key Features)

1. **বুদ্ধিমান সেলস অ্যাসিস্ট্যান্ট**:
   - গ্রাহক যেভাবে কথা বলবে (বাংলা, বাংলিশ বা ইংরেজি), বট ঠিক সেই ভাষায় মার্জিত ও বন্ধুসুলভভাবে উত্তর দেবে।
   - গ্রাহকের বাজেট বা পছন্দ অনুযায়ী প্রোডাক্ট খুঁজে বের করা এবং ছবি সহ বিবরণ প্রদর্শন করা।

2. **স্বয়ংক্রিয় অর্ডার গ্রহণ (Checkout)**:
   - গ্রাহকের নাম, মোবাইল নম্বর, সম্পূর্ণ ডেলিভারি ঠিকানা সংগ্রহ।
   - ক্যাশ অন ডেলিভারি (COD) অথবা বিকাশ/নগদ পেমেন্ট সমর্থন।
   - স্বয়ংক্রিয় অর্ডার আইডি তৈরি (যেমন: `#ORD-1001`) এবং ডেটাবেজে সংরক্ষণ।

3. **তাৎক্ষণিক অ্যাডমিন অ্যালার্ট**:
   - নতুন অর্ডার হওয়া মাত্রই অ্যাডমিনের টেলিগ্রামে গ্রাহকের সমস্ত তথ্য সহ নোটিফিকেশন পৌঁছাবে।

4. **২-ওয়ে স্মার্ট কাস্টমার সাপোর্ট ব্রিজ (Human Handover)**:
   - কাস্টমার যদি মানুষের সাথে কথা বলতে চায় বা কমপ্লেইন করে, অ্যাডমিনের কাছে সরাসরি অ্যালার্ট চলে যাবে।
   - **ম্যাজিক ফিচার:** অ্যাডমিন তার টেলিগ্রামে সেই নোটিফিকেশন মেসেজে **Reply** দিলে, বট স্বয়ংক্রিয়ভাবে সেই উত্তর গ্রাহকের কাছে পৌঁছে দেবে!

5. **অর্ডার ট্র্যাকিং ও পলিসি গাইড**:
   - গ্রাহক তার অর্ডার আইডি বা ফোন নম্বর দিয়ে বর্তমান স্ট্যাটাস জানতে পারবে।
   - ডেলিভারি চার্জ (ঢাকার ভেতরে ৮০৳, বাইরে ১৫০৳), ডেলিভারি সময় এবং রিটার্ন পলিসি স্বয়ংক্রিয়ভাবে বুঝিয়ে বলা।

6. **ক্যাটালগ সিঙ্কিং**:
   - `catalog.json` ফাইল এডিট করে অথবা গুগল শিট (Google Sheets CSV) থেকে সরাসরি প্রোডাক্ট ও স্টক সিঙ্ক করা যায়।

## 🚀 সেটআপ ও চালনার নির্দেশিকা (Quick Setup)

### ১. ফ্রি এপিআই কি ও টোকেন সংগ্রহ করুন:

#### ক. Telegram Bot Token:
1. টেলিগ্রাম অ্যাপে সার্চ করুন: `@BotFather`
2. তাকে `/start` পাঠিয়ে লিখুন `/newbot`
3. বটের নাম এবং একটি ইউজারনেম দিন (ইউজারনেমের শেষে `bot` থাকতে হবে)।
4. BotFather আপনাকে একটি **HTTP API Token** প্রদান করবে।

#### খ. Google Gemini API Key:
1. ব্রাউজারে যান: [Google AI Studio API Keys](https://aistudio.google.com/app/apikey)
2. আপনার গুগল অ্যাকাউন্ট দিয়ে লগইন করুন এবং **Create API key** বাটনে ক্লিক করে কি-টি কপি করুন (সম্পূর্ণ বিনামূল্যে)।

#### গ. আপনার নিজের Telegram Chat ID (অ্যাডমিন নোটিফিকেশন পাওয়ার জন্য):
1. টেলিগ্রামে সার্চ করুন: `@userinfobot`
2. তাকে `/start` পাঠালে সে আপনার সংখ্যাযুক্ত **ID** (যেমন `123456789`) দেখিয়ে দেবে।

---

### ২. কনফিগারেশন (`.env` ফাইল এডিট):

প্রজেক্টের `.env` ফাইলটি নোটপ্যাড বা কোড এডিটরে খুলে আপনার কি-গুলো বসিয়ে দিন:

```env
TELEGRAM_BOT_TOKEN=আপনার_টেলিগ্রাম_বট_টোকেন
GEMINI_API_KEY=আপনার_জেমিনি_এপিআই_কি
ADMIN_CHAT_ID=আপনার_টেলিগ্রাম_চ্যাট_আইডি

STORE_NAME="স্মার্ট গ্যাজেট ও লাইফস্টাইল শপ"
DELIVERY_FEE_INSIDE_DHAKA=80
DELIVERY_FEE_OUTSIDE_DHAKA=150
BKASH_NUMBER="01700000000 (Personal)"
NAGAD_NUMBER="01700000000 (Personal)"
CURRENCY="৳"
```

---

### ৩. বট চালু করুন:

টার্মিনালে নিচের কমান্ডটি রান করুন:

```bash
uv run python bot.py
```

বট সফলভাবে চালু হলে কনসোলে মেসেজ দেখাবে:
`✅ Bot is polling for messages. Press Ctrl+C to stop.`

এখন আপনার টেলিগ্রাম অ্যাপে বটের কাছে গিয়ে `/start` চাপুন এবং চ্যাট শুরু করুন!

## 🛒 প্রোডাক্ট ক্যাটালগ যোগ ও আপডেট করার নিয়ম

### পদ্ধতি ১: `catalog.json` ফাইল দিয়ে (সবচেয়ে সহজ)
`catalog.json` ফাইলটিতে প্রোডাক্টের তালিকা রয়েছে। আপনি সেখানে নতুন প্রোডাক্ট যুক্ত করতে পারেন:
```json
{
  "id": "PROD-107",
  "name": "Magnetic Wireless Car Charger",
  "category": "Accessories",
  "price": 1250,
  "description": "15W fast magnetic charging with 360-degree rotation.",
  "stock": 20,
  "image_url": "https://images.unsplash.com/..."
}
```
ফাইল সেভ করার পর টেলিগ্রামে অ্যাডমিন চ্যাট থেকে `/sync` কমান্ড দিন, সাথে সাথে ডেটাবেজ আপডেট হয়ে যাবে!

### পদ্ধতি ২: Google Sheets দিয়ে
1. গুগল ড্রাইভে একটি শিট তৈরি করুন যেখানে কলামগুলো থাকবে:
   `id`, `name`, `category`, `price`, `description`, `stock`, `image_url`
2. গুগল শিটের **File > Share > Publish to web** অপশনে যান।
3. ফরম্যাট হিসেবে **CSV** সিলেক্ট করে পাবলিশ করুন এবং প্রাপ্ত লিংকটি কপি করুন।
4. আপনার `.env` ফাইলে `GOOGLE_SHEETS_CSV_URL="প্রাপ্ত_লিংক"` বসিয়ে দিন।
5. টেলিগ্রাম থেকে `/sync` কমান্ড দিলে গুগল শিটের সমস্ত ডাটা এক ক্লিকে বটে সিঙ্ক হয়ে যাবে।

## 📱 টেলিগ্রাম কমান্ড তালিকা

### সাধারণ গ্রাহকদের জন্য:
- `/start` - বটের স্বাগত বার্তা ও ইন্টারেক্টিভ মেনু
- `/help` - বট ব্যবহারের নিয়মাবলী
- `/catalog` - শীর্ষ প্রোডাক্টসমূহের তালিকা
- `/track` - অর্ডার ট্র্যাক করার নির্দেশনা
- `/clear` - আগের চ্যাট হিস্ট্রি রিসেট করা

### অ্যাডমিনদের জন্য:
- `/admin` - অ্যাডমিন কন্ট্রোল প্যানেলের গাইড
- `/orders` - সর্বশেষ ১০টি অর্ডারের বিস্তারিত তালিকা
- `/status <ORDER_ID> <STATUS>` - অর্ডারের স্ট্যাটাস পরিবর্তন করা (যেমন: `/status ORD-1001 Shipped`)
- `/sync` - ক্যাটালগ ও স্টক রিফ্রেশ করা

## 👨‍💼 ২-ওয়ে সাপোর্ট ব্রিজ কীভাবে কাজ করে?
1. কোনো গ্রাহক যখন সাপোর্ট চায় বা অভিযোগ জানায়, অ্যাডমিন চ্যাটে একটি অ্যালার্ট যাবে যাতে কাস্টমারের নাম ও মেসেজ থাকবে।
2. অ্যাডমিন সরাসরি টেলিগ্রামের ইন-বিল্ট **"Reply"** অপশন দিয়ে মেসেজের উত্তর লিখবেন।
3. বট তাৎক্ষণিকভাবে সেই উত্তর গ্রাহকের ইনবক্সে "কাস্টমার সাপোর্ট ম্যানেজারের বার্তা" হিসেবে পৌঁছে দেবে।
